I build modern, accessible interfaces and I like understanding the product end to end — from the
data model to the final UI. My home turf is the React ecosystem (Next.js + TypeScript), but I move
comfortably around the backend with Laravel and SQL.

Before becoming a dev I was a STEAM educator, teaching Arduino and robotics to teenagers. That's
still where my love for electronics comes from — you'll find a few circuits among the repos below.
